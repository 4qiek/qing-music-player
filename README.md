# 清 · 灰白风桌面播放器（含安卓版）

一个用 Electron 写的极简桌面播放器，灰白配色，支持本地音乐、视频、图片、书籍和内嵌浏览器。

> 本仓库同时收录了安卓版：见 [`android/`](android/README.md)，原生 Kotlin + Media3，
> 面向 Android 8.0 及以上的通用安卓设备。支持中英双语、字体自定义，
> 可选择性联网补全封面与歌词（设置里可关，关掉后完全离线）。
> 两端共享设计语言，代码各自独立。

> **v1.3.0 起已移除在线音乐功能**（网易云 / QQ / 酷狗的搜索、播放、登录、排行榜、推荐与云端歌单）。
> 保留的两项联网增强仅供本地文件使用：按歌名匹配封面/歌手信息，以及匹配歌词。

## 功能

**音乐**
- 导入本地文件夹或单个文件，自动扫描入库并监听文件夹新增
- 内嵌 ID3 标签读取（标题 / 艺术家 / 专辑 / 封面 / 内嵌歌词）
- 可选「匹配线上信息」：按歌名补全歌手、专辑、封面与歌词（匹配失败自动回退到内嵌标签）
- 十段均衡器 + 预设、磁带音效、频谱可视化
- 桌面歌词（可拖动）、迷你模式、睡眠定时、托盘最小化
- 本地歌单、收藏、播放历史、播放队列

**其它**
- 视频：倍速、字幕、画中画、断点续播
- 图片：幻灯片浏览
- 书籍：TXT / MD / EPUB，章节跳转、书签、护眼底色，自动识别 GBK 编码
- 内嵌浏览器：无痕浏览
- 天气页与城市诗句
- 自定义点缀色（顶栏调色板，5 种预设 + 自由取色，暗色模式自动映射）

## 开发

```bash
npm install        # 安装依赖
npm start          # 开发运行
npm run dist       # 打包 Windows 安装包
```

打包产物默认输出到上级目录的 `qing-dist-v4`。

## 结构

```
main/           Electron 主进程（窗口、托盘、IPC）
main-media.js   本地媒体库与 qing-file:// 流式协议
preload.js      渲染层 API 桥
src/index.html  界面
src/js/         渲染层模块
src/css/        样式
assets/         图标
android/        安卓版（原生 Kotlin + Compose + Media3，通用安卓设备）
```

## 说明

- 本地媒体通过一个自定义协议 `qing-file://` 流式读取，带 Range 支持，大文件拖动无需载入内存。
- 该协议有路径白名单保护：只有用户主动导入过的文件夹和文件可以被访问，白名单持久化在用户数据目录。
- 在线音乐相关的历史数据（收藏、历史、歌单中的在线条目）会在加载时自动过滤。
